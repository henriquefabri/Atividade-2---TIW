# Atividade 2 - TIW

Controle de gastos pessoais de um mês, feito com React, TypeScript e Tailwind CSS.

## Como executar
- Instale o Node.js 20 ou superior.
- Execute `npm install`.
- Execute `npm run dev` e abra o endereço indicado no terminal.

## Funcionalidades
Cadastro, edição e remoção de receitas e despesas, validação dos campos, filtros por tipo e categoria e resumo de valores em reais. O resumo considera todas as transações do mês, mesmo com filtros ativos. Os dados ficam em memória durante a sessão.
